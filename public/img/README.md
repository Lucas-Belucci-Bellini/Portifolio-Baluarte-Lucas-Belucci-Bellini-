## Como adicionar (pelo site do GitHub — mais fácil)

1. Abra o repositório no GitHub e entre na pasta `public/img/`.
2. Clique em **Add file → Upload files**.
3. Arraste as imagens já **renomeadas** conforme a tabela acima.
4. Em **Commit changes**, selecione a branch de trabalho e confirme.

## Dicas de qualidade

- Prefira **JPG** para fotos e **PNG** para imagens com texto/transparência.
- Largura recomendada: **1200px** a **1600px** (boa nitidez sem pesar).
- O recorte de jornal fica melhor com uma **foto/scan nítido e reto**.
